# I: 最初の顧客を、実際にどう取ったか — 事例と実測

取得日 **2026-08-12**

**この記録が埋める穴**: `MARKET_RESEARCH.md` は「45人に声をかけて何人返信したかを数えろ」と書いていますが、
**誰に、どこで、何と書いて送るのかを一度も書いていません。** その空白を埋めるための一次情報です。

**禁止事項との関係**: `MARKET_RESEARCH.md` §7 は「成功事例からの逆算」を禁じつつ、
**「成功者の事実（値段・時期・売り方）は使えるが、成功の理由の説明は証拠にならない」**としています。
本記録は前者だけを採ります。**「なぜうまくいったか」の説明は、本人のものでも採りません。**

## 1. Storemapper（Tyler Tringas）— 最初の5社は、1通のmailから2日で

出典: `https://tylertringas.com/chapter-5-getting-your-first-customers/`
および `https://tylertringas.com/storemapper/`（いずれも取得 2026-08-12）

### 1.1 最初の顧客

| 事実 | 値 |
|---|---|
| 最初の5社の出どころ | **1通の一斉mail** |
| 宛先の数 | **30〜40人**（絞り込み済み） |
| 成約までの時間 | **2日** |
| 宛先名簿の作り方 | **9か月の受託仕事の中で作った表計算** |

**この名簿こそが本体です。** 本人は先に道具を作って売り先を探したのではなく、
**受託で9か月かけて「その作業で困っている実名の相手」の表を作ってから**、そこに1通出しています。

`MARKET_RESEARCH.md` の経路1（現職・前職の関係者）が「手持ちの大半になる」としているのと、
実例が一致します。**ただし一致は1件です。**

### 1.2 使った張り込み先 4つ

| 場所 | やったこと |
|---|---|
| **配布元の掲示板**（Shopify・BigCommerce・Volusion・WooCommerce の各forum） | 質問に答え、**署名欄で名乗る**。狙った話題は「店舗地図」そのものと**「サイトを新しく立てる・移す」話題** |
| **求人・外注募集板**（oDesk・Elance＝現Upwork） | `store locator` で **RSSを作り、IFTTT で通知**。募集が出たら「**その人を雇う代わりにこれを**」と提案。**1件あたり約30秒**で、本人は「かなり高い成功率」と書いている |
| **地域の名鑑**（Yelp・Craigslist・Google の店舗一覧） | 店主に電話し、**その場で無料試用を入れてしまう** |
| **配布元の店**（Shopify app store） | 公開時点で**その分類の唯一のアプリ**。「店内の検索も、サポートからの紹介も全部来た」 |

**2番目が最も具体的で、最も移植しやすい手です。**
求人・外注の募集は「**その作業に、この金額を、いま払うと言っている実名の相手**」が公開されている場所です。
`MARKET_RESEARCH.md` の判定基準（金か時間をもう払っているか）を、**観測だけで満たします。**

### 1.3 やらなかったと明言しているもの

**有料広告・検索対策・紹介報酬・追跡広告。** 後年の記録でも
「**Adwords は無駄、友人紹介の仕組みは不発**」とし、効いたのは
**自然検索**と**「powered by」表示からの流入**の2つだったとしています。

### 1.4 その後の数字

| 時点 | 値 |
|---|---|
| 2014年10月 | 試用→有料の転換 **40〜42%** |
| 値段 | 月 **$19** / **$39** |
| 2015年2月 | 年換算 **$100,000** |
| 2016年5月 | 年換算 **$200,000** |
| 2017年10月 | 売却 |
| 対応の手間（2015年） | **週5日・1日1時間未満** |

> **転換40〜42%を §6.5.1 の1%と置き換えてはいけません。別の量です。**
> こちらは「**試用を始めた人**が有料になる率」、§6.5.1 の1%は「**無料で使い続けている人**が有料に移る率」です。
> 母集団が違います。前者の母数は既に申し込んだ人、後者の母数は無料利用者全体です。

### 1.5 この事例の限界

**1件です。** 梯子の6段目（実務家が公開した実績。生き残りだけを見る偏りあり）に属します。
同じやり方で失敗した人の記録は集められていません。**分母が無いので、成功率は出せません。**

事実として使えるのは「**30〜40人の絞った名簿に1通出して2日で5社**という結果が実在する」ことまでで、
「**30〜40人に出せば5社取れる**」ではありません。

## 2. 日本語圏で同じ手が使えるか — 求人・外注募集板を実測

**Storemapper の2番目の手（求人・外注募集への張り込み）は、日本にも同じ場所があります。**
Lancers は**依頼件数・予算・提案数のすべてが登録なしで見えます**。

測定日 **2026-08-12** / `https://www.lancers.jp/work/search?keyword=<語>`

| 検索語 | 該当件数 | 上位の予算帯 | 提案数 |
|---|---|---|---|
| 在庫管理 | 5,303件 | 1万〜30万円 | 0〜1人 |
| 自動化 | 5,115件 | 1万〜30万円 | 1〜2人 |
| 請求書 | 4,142件 | 0.5万〜20万円 | 1人 |
| Excel マクロ | 3,184件 | 1万〜2万円 | 1人 |
| スクレイピング | 3,126件 | 1万〜4万円 | 1〜3人 |
| 予約システム | 1,510件 | 0.1万〜6万円 | 1〜3人 |
| 勤怠管理 | 866件 | 1万〜7万円 | 1人 |

### 2.1 【重要】この件数を需要の指標に使ってはいけません

**検索語が依頼文の全体に当たるため、無関係な依頼が大量に混ざります。**
「請求書」の上位5件には**法人ロゴの制作**と**展示会用パネルのイラスト制作**が入っていました。
「Excel マクロ」の上位5件のうち4件は**アンケート回答の募集**です。

さらに**募集終了分を含みます**（「自動化」の上位4件はいずれも終了済みでした）。

**したがって件数は捨てます。使うのは個票だけです。**

### 2.2 使えるのは1件1件の依頼

**1件の依頼＝「その作業に、この金額を、いま払うと言っている実名の相手」**です。
推定が1つも入っていません。`MARKET_RESEARCH.md` §1 の梯子で言えば2段目（公開されている実測値）に相当します。

**提案数がほぼ全件0〜1人**である点も観測事実です。競合の少なさとも読めますが、
**募集終了分を含む数え方なので、この解釈は保留します。**

### 2.3 着手前に必ず確認すべきこと（未確認）

> **Lancers・CrowdWorks の規約で、依頼者への直接取引の持ちかけ・外部サービスへの誘導が
> 禁じられている可能性があります。今回確認していません。**
> **ここが禁止なら、この経路は成立しません。** 声をかける前に規約本文を読んでください。
> 提案文の中で自分の道具を案内する形が許されるか、が分かれ目です。

その他の未確認: 予算はすべて**単発**で、継続課金の相場ではありません。
継続課金へ載せ替えられるかは、この数値からは何も言えません。

## 3. 日本語圏で、相手が居る場所（名指し）

**`MARKET_RESEARCH.md` は経路を4つの類型で書いていましたが、実在の場所を1つも挙げていませんでした。**
以下は名前を挙げただけで、**到達量は測っていません。**

| 経路 | 実在の場所 |
|---|---|
| 求人・外注募集（金が既に動いている） | Lancers、CrowdWorks、ココナラ（依頼を探す側）、Indeed の業務委託枠 |
| 詰まっている当事者が書いている場所 | Qiita、Zenn、teratail、Yahoo!知恵袋、X |
| 配布元の掲示板 | WordPress.org のsupport forum、各配布元のcommunity |
| 出品して数える | BOOTH、ココナラ、note、DLsite |
| 当事者の集まり | 業種別のSlack・Discord、商工会議所の部会、業界団体の勉強会 |
| 展示会 | 日本展示会協会の開催一覧（`MARKET_RESEARCH.md` §6.5.4。**94.4%が平日のみ**） |

**Qiita・Zenn・teratail・知恵袋は「困りごとを拾う場所」であって「声をかける場所」ではありません。**
返信で営業すると規約と空気の両方に触ります。ここで拾うのは**言い回し**で、
声をかけるのは経路1（現職・前職）と求人・外注募集です。
