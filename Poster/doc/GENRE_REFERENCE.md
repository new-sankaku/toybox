# GENRE REFERENCE — 実物パッケージ調査

POSTER FORGE の6 genre を「並べたときに別物に見える」状態にするための reference。
実装 module（`js/text/`・`js/render/`）が直接参照できる粒度で書く。

## 0. この文書の使い方

### 0-1. 数値の区分

| 記号 | 意味 |
| --- | --- |
| **[出典]** | 調査で確認した実物の規格値・実測値。変更してはいけない |
| **[設計]** | 出典の構造から導いた実装目標値。調整可 |

### 0-2. 最重要の前提

**genre の差は「語彙」ではなく「slot 集合そのもの」で出る。**

現行実装は6 genre すべてが `title / catch / sub / tag / badge / credit / release / extra` という
同一 slot 集合を共有している。実物はそうなっていない。

- 映画ポスターに「収録時間」は載らない
- 文庫の表1に「品番」は載らない
- ASMR に「興行成績」も「賞」も載らない
- ゲームパッケージに「三人称叙述の2文キャッチ」は載らない
- AV パッケージにおいて「タイトル」と「煽り」は分離していない（一体化した長い1文字列）

slot 集合が同じである限り、語彙をいくら足しても顔は同じになる。
**まず slot 集合を genre ごとに別テーブルにすること。**

### 0-3. 全 genre 共通の禁じ手

現行の catch pattern に全 genre 共通で入っている
`{clauseA}。{connective}、{clauseB}。`（三人称叙述の2文＋接続詞）は、
**映画（日本版）と小説の2 genre でしか成立しない。**
他の4 genre では最優先で撤去する。

## 1. 映画ポスター（cinema）

日本版（邦画・洋画日本版）と洋画オリジナル版は**別 layout として扱う**。
同じ genre 内の variant にすると、どちらの特徴も薄まる。

### 1-A. 情報要素

#### 日本版（劇場用ポスター）

| 要素 | 必須 | 典型文字数 | 行数 | 位置の定石 |
| --- | --- | --- | --- | --- |
| 惹句（キャッチコピー） | 必須 | 8〜28字 | 1〜3行 | 上部 y=4〜18%、または画像中央上 |
| タイトル | 必須 | 2〜14字 | 1〜2行 | 中央〜下部 y=55〜75%、横位置は中央 |
| 英字タイトル併記 | 任意 | 6〜24字 | 1行 | タイトル直下、字送りを広げる |
| 出演者名の並び | 必須 | 3〜7名 | 1〜2行 | タイトル上 y=48〜55%、または最上部 y=2〜6% |
| 原作クレジット | 任意 | 12〜30字 | 1行 | 惹句の下 or タイトル脇 |
| 賞・映画祭バッジ | 任意 | 10〜24字 | 1〜2行 | 左上 or 右上の角、月桂冠図形と組む |
| 興行・動員の数値 | 任意 | 6〜16字 | 1行 | 上部帯 or タイトル直上 |
| 推薦コメント | 任意 | 12〜30字＋発言者 | 2行 | 右上 or 左下、鉤括弧付き |
| 公開日 | 必須 | 10〜24字 | 1行 | 最下部 y=88〜94%、横中央 |
| billing block | 必須 | 120〜300字 | 4〜9行 | 最下部 y=92〜98%、極小・超コンデンス |
| 配給・製作ロゴ列 | 必須 | — | 1行 | billing block の下 or 上 |
| 映倫区分 | 任意 | 1〜5字 | — | 最下部の角、小さな囲み |
| 公式サイト／ハッシュタグ | 任意 | 10〜24字 | 1行 | 最下部 |

**日本版の決定的特徴**：海外版が「作品の一部」として作られるのに対し、日本版は
「集客のための広告」として設計される。主演を前面に出し、キャッチコピー・監督名・
キャスト名・簡単なあらすじ・原作情報を入れ込んで**情報量が意図的に多い**。
初動一発勝負の構造ゆえ「安心材料を全部載せる」設計になる。

#### 洋画オリジナル版（one sheet）

| 要素 | 必須 | 典型文字数 | 位置 |
| --- | --- | --- | --- |
| キャスト名の横一列（全大文字） | 必須 | 3〜5名 | 最上部 y=3〜7% |
| タイトル | 必須 | 1〜4語 | 中央下 y=62〜78% |
| tagline | 任意 | 3〜10語（英語1行） | タイトルの直上 or 直下 |
| billing block | 必須 | 40〜80語 | y=90〜96% |
| ロゴ列 | 必須 | — | y=96〜99% |
| 公開日 or `COMING SOON` | 必須 | 2〜6語 | billing block の直上 |
| 規格表記（IMAX / DOLBY 等） | 任意 | 1〜3語 | ロゴ列と同じ行 |

**日本版と洋画版の文字要素数の差**：日本版は洋画版に対して要素種類が概ね2倍。
洋画版は tagline が**存在しないことも多い**が、日本版で惹句が無いことはほぼ無い。

#### billing block の順序 [出典]

契約と guild 規定で順序が固定される。実装ではこの順序を守る。

```
{社名}PICTURES 提供   in association with {社名}
a {人名} production   a film by {人名}
{タイトル}
{俳優} {俳優} {俳優}
casting by {人名}   costumes by {人名}   edited by {人名}
production designer {人名}   director of photography {人名}
music by {人名}
executive producers {人名} {人名}
produced by {人名}
screenplay by {人名}   based on {出典}
directed by {人名}
```

WGA / DGA は所属会員の credit を**タイトルの15%以上の大きさ**にすることを要求する [出典]。
実装では `titleSize * 0.15` を billing block の下限にすればそれらしくなる。

### 1-B. 文言の文体

| 観点 | 日本版 | 洋画オリジナル版 |
| --- | --- | --- |
| 声 | 三人称叙述／無人称の宣言 | 無人称の宣言のみ |
| 文の型 | 断定・体言止め・倒置・問いかけ | 全大文字の断定1行 |
| 語尾 | 「〜だ」「〜する」「〜ない」「〜。」体言止め | ピリオド or 無し |
| 記号 | `。` `、` `――` `、` `／` 改行 | `.` のみ。感嘆符は稀 |
| 数値 | 興行収入・動員数・カ国数・映画祭回数・公開日 | 公開日のみ |
| 禁じ手 | `！！` の連打／`♪` `♡`／収録時間／品番／トラック数／価格 | 日本語すべて／数値の羅列 |

**惹句の構文型（日本版）**

- 対比型：`{句A}。{接続}、{句B}。`
- 宣言型：`いま、{名詞}が{動詞}。`
- 否定型：`{名詞}は、{動詞}ない。`
- 名詞句止め型：`{形容}{名詞}の、{名詞}。`
- 呼びかけ型（稀）：`さよなら、{名詞}。`

**「惹句は1行または2行、24字以内」を上限とする [設計]**。
現行実装の catch は3文以上に伸びることがあり、これが「小説の帯」に見える主因のひとつ。

### 1-C. 版面

| 項目 | 値 |
| --- | --- |
| 判型（日本 B1） | 728 × 1030 mm → w/h = **0.707** [出典] |
| 判型（日本 B2） | 515 × 728 mm → w/h = **0.707** [出典] |
| 判型（日本 speed poster） | 255 × 728 mm → w/h = **0.350** [出典] |
| 判型（日本 タテカン） | 515 × 1456 mm → w/h = **0.354** [出典] |
| 判型（US one sheet） | 27 × 40 inch → w/h = **0.675** [出典] |
| 文字要素の面積比（日本版） | **22〜35%** [設計] |
| 文字要素の面積比（洋画版） | **10〜16%** [設計] |
| 組方向 | 横組みが主。惹句のみ縦組みにする variant あり |
| 枠 | 全面写真＋下部に暗い gradient scrim。明示的な枠線は使わない |

**下部 scrim は必須**。billing block を読ませるため、y=85〜100% に
黒 → 透明の縦 gradient を入れるのが実物の定石。

### 1-D. 文字装飾

| 要素 | 日本版 | 洋画版 |
| --- | --- | --- |
| タイトル書体 | 極太明朝 or 太ゴシック。縦横比を 0.85〜0.95 に潰す | serif / sans の大文字、字間 +80〜200 |
| タイトル装飾 | 白 or 金の1〜2重袋文字＋薄い long shadow。metallic gradient は年代物 | 単色ベタ。装飾ほぼ無し |
| 惹句 | 白ベタ or 白＋1px 縁。書体はタイトルより細い明朝 | — |
| billing block | 超コンデンス（幅 35〜45%）・全大文字・字間 0 | 同左（Univers 39 Thin Ultra Condensed 系）[出典] |
| バッジ | 月桂冠図形＋細ゴシック、金 or 白 | 同左 |

**タイトルと補助情報の装飾差**：タイトルにのみ袋文字・影を許す。
惹句以下はすべて無装飾（scrim に頼る）。この差自体が映画らしさになる。

### 1-E. 配色

| 項目 | 値 |
| --- | --- |
| 支配色域 | 画像由来。teal & orange の split tone が定番 |
| 彩度 | 中〜低（S 0.25〜0.55）。日本版はやや高め |
| 明度 | 下部を暗く落とす（L 0.10〜0.25） |
| 文字色 | 白 #FFFFFF が最頻。次点で金（H 40〜48 / S 0.55 / L 0.62） |
| バッジ色 | 金 or 白 |
| 記号性 | 金＝賞・格式／赤＝アクション・熱／青緑＝SF・寒色サスペンス |

### 1-F. 文言 template（20件）

可変部は `{}`。実在名は入れず、**型**として記述する。

**惹句**
1. `{名詞}は、{動詞}ない。`

### 1-G. 判別ポイント

1. **最下部に極小・超コンデンスの多行 credit の塊がある**（他 genre に一切無い）
2. **公開日が「◯月◯日（◯）全国ロードショー」形式で最下部中央**
3. **金色の月桂冠バッジ**が角にある
4. 惹句が**画像の上部に、タイトルとは別の書体で**置かれる
5. 品番・収録時間・価格・トラック数が**一切載らない**

## 2. グラビア／イメージビデオ DVD ジャケット（gravure）

### 2-A. 情報要素

DVD ビデオの表示事項は日本レコード協会規格 **RIS 403** で定義される [出典]。
表1（ジャケット表面）に載るのは以下。裏カード・背に載る項目と**明確に分かれている**。

| 要素 | 必須 | 典型文字数 | 位置の定石 |
| --- | --- | --- | --- |
| 出演者名 | 必須 | 3〜8字 | **最大級。上部 y=6〜18% または下部 y=72〜82%** |
| 作品タイトル | 必須 | 4〜16字 | 出演者名の直下・直上。出演者名より小さいことが多い |
| コピー1行 | 任意 | 10〜24字 | タイトルの上下いずれか |
| レーベル・マーク | 必須 | — | 角。表1では小さく |
| 規格表記（DVD / Blu-ray） | 必須 | 3〜8字 | 上部帯 or 下部帯 |
| 収録時間 | 必須（表4/背） | 6〜14字 | 表1では下部帯に入る variant あり |
| 特典表記 | 任意 | 8〜20字 | **斜めタスキ or 円形バッジ**、角 |
| 商品番号（品番） | 必須 | 8〜12字 | 表1の隅 or 背。極小 |
| 価格 | 必須 | 8〜14字 | 下部帯。**10級（7pt）以上の太字**が規格 [出典] |
| 発売年月日 | 必須 | 8〜10字 | 下部帯。**7級（5pt）基準の明瞭書体**が規格 [出典] |
| 発売会社名 | 必須 | 6〜16字 | 下部帯 |

**タスキ（帯）**：ジュエルケース仕様の「キャップ」に相当する要素。
RIS 403 は「キャップ表面 10mm 以上（半タスキの場合 6mm 以上）」を規定 [出典]。
実装では**表1の下 12〜20% を占める横帯**として扱えばよい。斜め帯を使うのは AV の作法で、
gravure は**水平帯**が基本。

### 2-B. 文言の文体

| 観点 | 値 |
| --- | --- |
| 声 | 販促の無人称。まれに三人称叙述（1文のみ） |
| 文の型 | 体言止め主体。名詞句＋読点で切る。命令形は使わない |
| 語尾 | 「〜。」で止めるか、語尾を作らず名詞で終える |
| 記号 | `、` `。` `／` `＋` `♪` は稀。**`！！` は使わない** |
| 数値 | 収録時間（分）／特典分数／撮影日数／枚数／価格／品番／年齢 |
| 禁じ手 | 興行成績・映画祭・受賞・部数・週間順位・トラック数・CV表記・plat form 名 |

**gravure と cinema の分かれ目**：gravure は**時間と特典の数値**を出し、
cinema は**興行と賞の数値**を出す。同じ「数値 slot」でも意味論が違う。

### 2-C. 版面

| 項目 | 値 |
| --- | --- |
| DVD トールケース | 191 × 132 mm（外寸）[出典] |
| ジャケット表1 パネル | 183 × 129.5 mm → w/h = **0.708** [出典] |
| ジャケット展開（背14mm） | 183 × 273 mm [出典] |
| 文字要素の面積比 | **18〜28%** [設計] |
| 組方向 | 横組み。出演者名のみ縦組みにする variant あり |
| 帯 | 下部に水平帯。高さ = 版面の 12〜20% [設計] |
| 枠 | 上下に細い罫（1〜3px）を入れる variant が多い |

### 2-D. 文字装飾

| 要素 | 装飾 |
| --- | --- |
| 出演者名 | 太ゴシック or 丸ゴシック。**白の袋文字1重＋薄い drop shadow** |
| 作品タイトル | 明朝 or 筆書き系。装飾は控えめ。字間を広げる |
| コピー | 細ゴシック。無装飾 |
| 特典バッジ | 極太ゴシック白抜き、ベタ板（円 or 角丸）に載せる |
| 下部帯の文字 | 極小ゴシック。等幅感を出す |

袋文字は**1重まで**。2重以上・bevel・metallic は AV の作法なので gravure では使わない。

### 2-E. 配色

| 項目 | 値 |
| --- | --- |
| 支配色域 | 明るい高明度（L 0.60〜0.85）。水色・白・淡いピンク・砂色 |
| 彩度 | 中（S 0.30〜0.55）。原色ベタは避ける |
| 帯の色 | 白 or 淡い単色ベタ。文字は濃色 |
| バッジ色 | 赤・オレンジ・黄 |
| 記号性 | 水色＝夏・海／淡ピンク＝春・室内／白＝清潔感。**黒背景はほぼ使わない** |

### 2-F. 文言 template（22件）

**タイトル・コピー**
1. `{季節}の{場所}で`
2. `はじめての{名詞}`
3. `{場所}、{数}日間`

5. `{数}歳、{名詞}。`
6. `{名詞}のとなりで`
7. `{場所}ロケ敢行`

**収録・特典**

**書誌**

### 2-G. 判別ポイント

1. **出演者名がタイトルより大きい**（他 genre では逆）
2. **下部に水平な帯**があり、そこに 収録時間／発売日／価格／品番 が横一列で並ぶ
3. **円形 or 角丸のベタ板バッジで特典を告知**（右上 or 左上）
4. 高明度・中彩度で、**画面全体が明るい**
5. 賞・部数・順位の数値が一切無い。**数値はすべて「分」「枚」「円」「日」**

## 3. 日本の文庫本の書影と帯（novel）

### 3-A. 情報要素

| 要素 | 必須 | 典型文字数 | 位置の定石 |
| --- | --- | --- | --- |
| タイトル | 必須 | 2〜12字 | **縦組み。右寄せ x=68〜88%、上から 8〜45%** |
| 著者名 | 必須 | 3〜8字 | タイトルの左下 or 下部。タイトルの 40〜60% の大きさ |
| レーベル名 | 必須 | 4〜8字 | 下部 or 背。小さく |
| レーベルマーク | 必須 | — | 表1の下端中央 or 隅 |
| 帯メインコピー | 必須 | **15〜25字** [出典] | 帯の上段。読まれる順序の①|
| 帯サブコピー1 | 任意 | 20〜40字 | 帯の中段。②|

**タイトル文字列が構造を持つ**のがこの genre の核心。実物の型は：

```
【{タグ}】【{タグ}】{メイン}～{サブ}～【CV：{人名}】
```

タグは「収録機材」「効果の種類」「シチュエーション」「所要時間」など**性質の列挙**。
複数の `【】` を先頭に積むこと自体が判別記号になる。

6 genre 中もっともタイトル文字列が長い。ただし版面上は
タグ列・メイン・サブ・CV に**分解して多段配置**する。

## 6. アダルトビデオのパッケージ（adult）

**本節は文字組み・情報設計・販促文言の体裁のみを対象とする。**
画像の内容・被写体・性的表現は対象外。以下は書誌情報と販促定型の形式論に限定する。

### 6-A. 情報要素

DVD ビデオである以上、表示事項は RIS 403 の枠組みに乗る [出典]。
そのうえで、この genre 固有の情報設計がある。

| 要素 | 必須 | 典型文字数 | 位置の定石 |
| --- | --- | --- | --- |
| タイトル（煽りと一体） | 必須 | **平均22語相当・40〜120字** [出典] | 版面の 40〜70% を縦断。多段組 |
| 出演者名 | 必須 | 3〜8字 | 上部 or 下部の帯。タイトルより小さい場合が多い |
| 斜めタスキの煽り | 任意 | 6〜18字 | **左上→右下 or 右上→左下の斜め帯**（−12〜−28°） |
| シリーズ名 | 任意 | 4〜14字 | 上部の小帯 |
| メーカー名／レーベル名 | 必須 | 4〜16字 | 下部帯 or 隅 |
| 品番 | 必須 | 6〜12字 | 下部帯の右端 or 背 |
| 収録時間 | 必須 | 6〜16字 | 下部帯 |
| 発売日 | 必須 | 8〜10字 | 下部帯 |
| 価格 | 必須 | 8〜14字 | 下部帯 |
| 規格表記 | 必須 | 3〜10字 | 上部 or 下部帯 |
| 年齢制限表示 | 必須 | 10〜24字 | 下部、小さく |
| 注記（フィクション表記等） | 必須 | 12〜30字 | 最下部、極小 |
| 特典表記 | 任意 | 6〜16字 | 角のバッジ |

**この genre の情報設計上の核心** [出典]

- **タイトルと煽り文が分離していない。** タイトル自体が属性の列挙になっている。
  実装で `title` と `catch` を別 slot にしていると、この genre だけ再現できない。
- 名詞が全体の約 **50%**、助詞は約 **16%** [出典]。助詞を削って名詞を並べる。
- 目的格「を」の使用が多く、**外部視点の構文**になる。
- 平均語数 22.2語（ライトノベル 10.2語の約2倍）[出典]。
- 「単体もの」は文字が少なく整った版面、「企画もの」は**余白なしに文字を詰める** [出典]。
  この2 variant を実装で分けると幅が出る。
- 版面の**上部は穏やか、下部にいくほど情報が過激・派手**になる緩急設計 [出典]。
  実装では「上部＝タイトルと出演者名、下部＝煽りとバッジと帯」に対応させる。

**品番の型** [出典（DVD 商品番号一般）]

| 型 | 形 |
| --- | --- |
| 標準型 | `{英字3}-{数字3}` |
| 長桁型 | `{英字4}-{数字5}` |
| 接頭数字型 | `{数字1}{英字3}-{数字3}` |
| 英数混在型 | `{英字3}-{英字2}{数字3}` |
| 枝番型 | `{英字4}-{数字2}{英字1}` |

RIS 403 における商品番号は「外観から明瞭かつ容易に読み取れるように表示する」ことが
求められ、価格は **10級（7pt）以上の太字**、発売年月日は **7級（5pt）基準の明瞭書体**
と規定される [出典]。実装ではこの2つだけ他の極小文字より一段大きくする。

### 6-B. 文言の文体

| 観点 | 値 |
| --- | --- |
| 声 | **販促の無人称**のみ。叙述も呼びかけも使わない |
| 文の型 | **属性の羅列**。名詞句を `！` `／` `、` で連結。体言止めで終わる |
| 語尾 | 語尾を作らない（名詞で終わる）。動詞で終わる場合は連用中止 |
| 記号 | **`！！` `!!` `＆` `×` `／` `＋` `【】` `＜＞`**。`。` はほぼ使わない |
| 数値 | 品番／収録時間（分・時間分）／本編＋特典の内訳／シリーズ第◯弾／周年／シーン数／価格／発売日 |
| 禁じ手 | 賞・映画祭・興行成績・部数・週間順位・トラック数・CV表記・プラットフォーム名・`♪`・三人称叙述の2文 |

**表現規制由来の書式** [出典]：伏せ字・漢字の置換・注記の併記が体裁として存在する。
実装では「伏せ字記号（`◯` `＊`）を1〜2文字混ぜる」という**形式だけ**を再現すればよい。

## 8. 現行実装との差分（実装 Agent 向けの指摘）

### 8-1. slot 集合が全 genre 共通になっている

`js/text/patterns.js` は6 genre すべてが
`title / catch / sub / tag / badge / credit / release / extra` の8 slot を持つ。
実物では slot 集合そのものが異なる。**genre ごとに slot の定義から分ける**。

推奨 slot 集合：

| genre | slot |
| --- | --- |
| cinema | `catchLine` `title` `titleEn` `castRow` `award` `boxOffice` `sourceCredit` `releaseLine` `billingBlock` `logoRow` `ratingMark` |
| gravure | `performer` `title` `copyLine` `bonusBadge` `specRow(収録時間/発売日/価格/品番)` `label` `formatMark` |
| novel | `title(縦)` `author` `obiMain` `obiSub` `obiBox` `imprint` `spineCode` `blurb(150-200字)` `priceLine` |
| asmr | `tagRow(【】×2-4)` `title` `subtitle(～～)` `cvLine` `circle` `specRow(分/トラック/形式)` `staffLine` |
| game | `platformBand` `titleLogo` `subtitle` `edition` `catchLine(命令形)` `ratingPlate` `publisherRow` `copyrightLine` |
| adult | `megaTitle(40-120字・書式不統一)` `performer` `sashBand(斜め)` `series` `specRow(品番/時間/発売日/価格)` `maker` `noticeLine` |

### 8-2. catch pattern が全 genre で同一構文

6 genre すべての `catch` 配列の先頭が
`'{clauseA}。{connective}、{clauseB}。'` で始まっている。
この「三人称叙述の2文＋接続詞」は **cinema と novel 以外では実物に存在しない**。

- gravure → 体言止め1文へ
- asmr → 二人称呼びかけへ
- game → 命令形・勧誘へ
- adult → 名詞の羅列（助詞16%）へ

### 8-3. asmr の縦横比が誤り

`doc/REQUIREMENTS.md` の「正方形に近い比率」は実物と異なる。
DL 販売 platform のメイン画像は **560 × 420 px（4:3 横長）** [出典]。
正方形は 300×300 の thumbnail 規格であって、ジャケット本体ではない。

### 8-4. adult の title と catch を分離している

現行は `title` と `catch` が別 slot だが、この genre の核心は
**タイトルと煽りが分離していない**点にある。`megaTitle` 1 slot に統合し、
その内部で書式（サイズ・色）を3〜5段階に変える renderer を持たせる必要がある。

### 8-5. 装飾の差が付いていない

`doc/DECOR_AND_COLOR.md` の内容を7-4表の値に合わせて再定義する。
特に **novel は装飾ゼロ**（袋文字0重・影なし・glow なし）でなければならない。
現在すべての genre に何らかの装飾が入っていると、全部が同じ顔になる。

### 8-6. 数値 slot の意味論が共有されている

`{n:code}` `{n:minutes}` `{n:price}` などが genre をまたいで使われている。
7-3表のとおり、**genre ごとに使ってよい数値 slot を制限する**。
cinema に `{n:code}`（品番）が入っている現状は誤り。

### 8-7. 帯構造が実装されていない

7-1表の「帯の構成」列が genre の骨格。
- novel：版面下 **34%** を不透明ベタで覆う
- game：上部 8〜12% の水平帯
- asmr：上下2帯
- adult：上小帯＋斜めタスキ＋下帯の3層
- gravure：下1帯
- cinema：帯なし（下部 scrim のみ）

これだけで6 genre は視覚的に分離する。
