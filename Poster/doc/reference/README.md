# 実物パッケージの参考画像

実物を観察するための画像をここに置く。ジャンルごとのfolderに入れる。

```
reference/
  cinema/    映画ポスター（劇場用one sheet）
  gravure/   image videoのDVD jacket
  novel/     文庫の書影と帯
  asmr/      音声作品のjacket
  game/      家庭用ゲームのpackage
  adult/     体裁の参考（文字組み・情報設計のみ）
```

file名は自由。`doc/GENRE_REFERENCE.md` の観察結果は、ここに置いた画像を直接見て書く。
記事のtextだけを読んで書いた記述は信用しない。
